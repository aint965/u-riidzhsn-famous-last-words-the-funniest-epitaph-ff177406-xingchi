Entry for the make.fun competition **Famous Last Words: The Funniest Epitaph**
(`u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406`), by @aint965.

`main.py` writes one line of famous last words — a single tombstone epitaph,
at most 150 characters — to `/output/entry.txt`:

> I told you so. The autopsy agrees.

The joke is posthumous vindication: the speaker was right all along, and the
autopsy is the witness that proves it. Deterministic, no network, no input —
the same line every run.
